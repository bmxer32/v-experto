# ВАШ Эксперт — Сайт оценочной компании

> Корпоративный сайт для независимой оценочной компании ООО «ВАШ Эксперт» (г. Иваново). Разработан под ключ: от дизайна до деплоя.

**Живой сайт:** [v-experto.ru](https://v-experto.ru)

---

## Стек технологий

| Технология | Назначение |
|---|---|
| **Next.js 15** (App Router) | Фреймворк, SSR, маршрутизация |
| **React 19** | UI-компоненты |
| **Tailwind CSS v4** | Стилизация |
| **Swiper.js** | Карусель в секции портфолио |
| **Telegram Bot API** | Отправка заявок с формы |
| **Yandex.Metrika** | Аналитика и вебвизор |
| **Vercel** | Деплой и хостинг |

---

## Функционал

- **Форма захвата лидов** — встроенная и модальная, с многоуровневой защитой от ботов:
  - Honeypot-поле
  - Time Trap (отсечение мгновенных отправок)
  - Rate Limiting по IP (1 заявка в 60 сек)
- **Telegram-интеграция** — мгновенное уведомление менеджера о новой заявке
- **SEO-оптимизация** — метатеги, Open Graph, динамический sitemap, robots.txt
- **Адаптивная вёрстка** — корректное отображение на любом устройстве
- **Страница услуг с ценами** — 9 категорий с раскрывающимися карточками
- **Яндекс.Карты** в секции контактов
- **Страница команды** с документами и сертификатами

## Запуск локально

```bash
# 1. Клонировать репозиторий
git clone https://github.com/your-username/v-experto.git
cd v-experto

# 2. Установить зависимости
npm install

# 3. Создать файл с переменными окружения
cp .env.example .env.local
# Заполнить TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID

# 4. Запустить dev-сервер
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000)

---

## Переменные окружения

Создайте файл `.env.local` в корне проекта:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_бота
TELEGRAM_CHAT_ID=id_чата          # Несколько получателей через запятую: 123,456
```

## Деплой

Проект готов к деплою на **Vercel**. Достаточно подключить репозиторий и добавить переменные окружения в настройках проекта.

```bash
npm run build   # Проверить сборку локально
npm start       # Запустить production-сервер
```

## О проекте

Разработан для **ООО «ВАШ Эксперт»** — независимой оценочной компании, работающей по всей России. Компания специализируется на оценке недвижимости, транспорта, бизнеса и имущества для нотариусов, судов и банков.

**Задачи, решённые в проекте:**
- Увеличить входящий поток заявок с сайта
- Убрать сторонние CRM — уведомления напрямую в Telegram
- SEO-оптимизация под локальные запросы Яндекса
- Соответствие 152-ФЗ (политика обработки персональных данных)
